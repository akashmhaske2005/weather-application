Coding Rules

We'll follow the same approach as your Todo App:

One file at a time.

One feature at a time.

Test after every feature.

Commit after every completed feature.


Example:

git add .

git commit -m "feat: build weather app UI"

git push origin main


---

Step 1 starts now

We'll not write any JavaScript yet.

The first milestone is to build a polished, responsive UI using only HTML and CSS that matches the design we planned. Once the UI is complete and looks good on desktop and mobile, we'll move on to connecting the APIs. This keeps layout problems separate from logic and makes debugging much easier.
