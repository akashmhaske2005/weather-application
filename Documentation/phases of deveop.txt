Step 1 starts now

We'll not write any JavaScript yet.

The first milestone is to build a polished, responsive UI using only HTML and CSS that matches the design we planned. Once the UI is complete and looks good on desktop and mobile, we'll move on to connecting the APIs. This keeps layout problems separate from logic and makes debugging much easier.

You have three realistic choices.

Use an image service (such as Unsplash or Pexels) to fetch a city/landmark image based on the weather location.

Flow:

↓

↓

City Name

Image API

↓

Background updates

Pros:

Looks professional

Cons:

One extra API call
Option C — Hybrid (My recommendation)
Open App

↓

Location Weather

↓

Default Background

↓

Weather visible immediately

↓

Image downloads

↓

Fade animation

↓

Background replaced

This gives the fastest perceived performance and the best UX.
